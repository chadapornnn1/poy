ขั้นตอนการนำเว็บนี้ขึ้น GitHub Pages

เผยแพร่เว็บไซต์ประวัติส่วนตัวของคุณให้เข้าถึงได้ทั่วโลกฟรี!

ขั้นตอนที่ 1: เตรียมไฟล์

บันทึกโค้ดนี้ไว้ในชื่อไฟล์ index.html ลงในคอมพิวเตอร์ของคุณ

ขั้นตอนที่ 2: สร้าง Repository บน GitHub

1. สมัคร/ล็อกอินบัญชี GitHub.com

2. คลิกปุ่ม New Repository ตั้งชื่อ เช่น my-portfolio แล้วกด Create Repository

ขั้นตอนที่ 3: อัปโหลดไฟล์ index.html

ในหน้า Repository คลิก uploading an existing file แล้วลากไฟล์ index.html ใส่ลงไป จากนั้นกด Commit changes

ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages

1. ไปที่เมนู Settings > Pages

2. ในหัวข้อ Build and deployment ให้เลือก Branch เป็น main (หรือ master) แล้วกด Save

3. รอ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น https://yourusername.github.io/my-portfolio พร้อมส่งให้อาจารย์หรือใส่ในแฟ้มสะสมผลงานได้ทันที!
